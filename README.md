# Aaira's birthday website

Static site (no build step). Deploy on Vercel:

**Drag and drop:** go to vercel.com/new, choose "Upload"/drag this folder in, deploy.
**CLI:** `npm i -g vercel`, then run `vercel --prod` inside this folder
(Framework preset: Other, no build command, output directory: leave empty).
**GitHub:** push this folder to a repo and import it at vercel.com/new.

Files: index.html, assets/ (4 photos + song), vercel.json.
